## 🚀 Explore what you can do

### 🛡️ 1. Browse with fewer distractions

Keep unwanted page elements under control with DEXTA's built-in content
blocker.

-   🚫 Filter-based ad and tracker blocking.
-   📋 Support for filter sources such as EasyList and EasyPrivacy.
-   🪟 Controls for pop-ups and redirects.
-   🎯 Per-website protection settings.
-   ➕ Custom blocked-domain list.

**Your browser, your rules:** adjust protection for a specific website
when something you need is blocked.

### 🔐 2. Privacy controls that put you in charge

Privacy is about useful choices and honest information --- not
unrealistic promises.

-   🕶️ Private tabs that do not add pages to browsing history.
-   🍪 Third-party cookie blocking option.
-   🛡️ Safe Browsing protection option.
-   ⚙️ JavaScript control.
-   🔒 Optional app lock using supported Android screen-lock or
    biometric authentication.
-   🧹 Clear browsing data whenever you choose.

**Remember:** Private browsing does not make you invisible to websites,
your internet provider, or network operators.

-   🎲 Password generator.

-   🚫 Passwords excluded from DEXTA's regular backup files.

## 🧩 Website not working? Try this

Some websites need pop-ups, redirects, third-party scripts, or other
resources that a blocker may restrict.

If a login window, payment page, video player, or website does not work:

1.  🌐 Open the affected website in DEXTA.
2.  🛡️ Open the browser's Ad Blocker settings.
3.  🪟 Temporarily turn **OFF Block pop-ups and redirects** if the site
    needs a pop-up or login window.
4.  🔕 If the issue continues, temporarily disable the ad blocker for
    that website.
5.  🔄 Reload the page and try again.
6.  ✅ Turn protection back on when you no longer need the exception.

If Strict Mode is enabled, try allowing the required site or turning
Strict Mode off for that site.

⚠️ **Stay safe:** only allow pop-ups or disable blocking on websites you
trust. These settings may allow unwanted content.

## 🔍 Privacy & transparency

We believe trust starts with clear information. Here's what the
inspected project indicates --- including where online services are
involved.

### ✅ What DEXTA is designed to do

-   No DEXTA account or registration is required.
-   The inspected project dependencies do not include a third-party
    advertising or analytics SDK.
-   Saved passwords are encrypted locally using Android Keystore-backed
    AES-256-GCM.
-   Regular browser backups exclude passwords and cookies.
-   Optional encrypted sync is file-based and passphrase-protected;
    DEXTA does not provide a cloud sync server.

### 🌐 When optional features connect to other services

Some features need online services to work. Here are examples:

  -----------------------------------------------------------------------
  Feature                             What happens
  ----------------------------------- -----------------------------------
  🌦️ Weather                          Open-Meteo receives approximate,
                                      rounded location coordinates when
                                      weather is used.

  🌍 Translation                      Text selected for translation is
                                      sent to Google's translation
                                      endpoint.

  🛡️ Safe Browsing                    Uses Google's Safe Browsing service
                                      when enabled.

  🔎 Search suggestions               Address-bar text may be sent to
                                      your selected search provider when
                                      suggestions are enabled.

  📰 News                             DEXTA requests the public RSS feed
                                      you select.

  🔄 Updates                          DEXTA checks its configured public
                                      update source for release
                                      information.
  -----------------------------------------------------------------------

Websites you visit can also receive information needed to load their
pages. Their own data practices are outside DEXTA's control.

### 🧾 A note about diagnostic logs

The inspected project contains a diagnostic logging component for
troubleshooting. It can write limited network and URL-path details to
Android system logs (Logcat). The code is configured to omit URL query
strings, fragments, cookies, and request/response headers.

This is device-side diagnostic logging, not evidence of an analytics
service. For that reason, DEXTA does **not** claim that absolutely no
logs are ever created or that all internet activity is anonymous.

## ⚠️ Good to know

A transparent browser should be clear about its limitations too.

-   DEXTA uses Android System WebView; it is not a separately packaged
    full Chromium browser.
-   Chrome Web Store extensions are not supported; DEXTA provides user
    scripts instead.
-   Strict Mode may affect websites that rely on cross-domain scripts or
    frames.
-   Some ads may still appear. No blocker can guarantee that every
    advertisement will be removed.
-   Download resume depends on the website's server supporting
    byte-range requests.
-   DEXTA's optional DNS-over-HTTPS feature applies to its own network
    requests; Android WebView page traffic uses the device's network
    resolver.
-   Android WebView may share cookies between regular and private tabs.
    Private browsing should not be treated as complete session
    isolation.
-   Translation depends on Google's public translation endpoint and may
    be rate-limited or changed by that service.
