What you can do

🛡️ Ad & tracker blocking

  • Filter lists such as EasyList and EasyPrivacy
  • Pop-up and redirect controls
  • Per-website settings and custom blocked domains
  • Optional Strict Mode
  • Blocked-request statistics

🔐 Privacy controls

  • Private tabs
  • Third-party cookie blocking option
  • Safe Browsing option
  • Optional app lock (screen lock or biometrics)
  • Clear browsing data any time

🔑 Password vault

  • AES-256-GCM encryption
  • Key protected by Android Keystore
  • Optional biometric unlock
  • Password generator and Android Autofill support
  • Passwords excluded from regular backups

🧰 Everyday tools

  • Tabs, private tabs, tab groups, pinned tabs
  • Bookmarks and history
  • Reader Mode and page translation
  • Desktop-site mode
  • Download manager with pause/resume where supported
  • Save pages as PDF

🌦️ Useful start page

  • Weather from Open-Meteo (°C / °F)
  • Optional news from public RSS feeds
  • Customisable shortcuts
  • Weather and news can be switched off

🧑‍💻 Developer tools

WebView developer tools with Elements, Console, Network, Sources and Application panels. Some advanced Chrome DevTools features are not available in Android WebView.

Install in a few steps

  1. Download the APK from the button above (it comes from the official GitHub Releases page).
  2. Open the downloaded file on your Android device.
  3. If Android asks, allow your browser or file manager to install apps from that source.
  4. Review the installation prompt and install DEXTA Browser.

🔐 For your safety, download the app only from this official repository. Android may show a warning when installing apps from outside Google Play. Once installed, DEXTA can check for updates itself and asks for your approval before installing.

Privacy & transparency

No DEXTA account is required. Saved passwords are encrypted on your device. Some optional features connect to other services: weather (Open-Meteo), translation and Safe Browsing (Google), search suggestions (your chosen search provider), news (the RSS feed you select) and update checks (this repository). Private browsing does not make you invisible to websites or network operators.

Read the full details in the README.

Good to know

  • DEXTA uses Android System WebView; it is not a separately packaged Chromium browser.
  • Chrome Web Store extensions are not supported; user scripts are supported instead.
  • No blocker can guarantee that every advertisement is removed.
  • If a website does not work, allow its pop-ups or turn blocking off for that site only, and only on sites you trust.
